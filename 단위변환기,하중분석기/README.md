# 공학용 단위 변환기 및 CSV 하중 분석기

## 공학용 단위 변환기

`force_converter.py`는 Tkinter 기반의 데스크톱 GUI 프로그램입니다. 다음 두 가지 기능을 제공합니다.

- 단위 변환
- 공학용 수식 계산

### 처음 설치

저장소를 처음 받았거나 `.venv`가 없는 경우, 저장소 폴더에서 다음 명령을 한 번 실행합니다.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
```

`tkinter`는 Python 설치에 포함된 표준 라이브러리이므로 별도 pip 설치가 필요하지 않습니다.

### 실행 환경

- Python 실행 환경
- Python 표준 라이브러리 `tkinter`
- 그래픽 데스크톱 환경

외부 패키지는 코드에서 사용하지 않습니다. `tkinter`를 사용할 수 있는 Python 환경이어야 하며, 터미널만 있는 환경에서는 GUI를 표시할 수 없습니다.

### 실행 방법

작업 폴더에서 다음 명령을 실행합니다.

```bash
.\.venv\Scripts\python.exe ".\단위변환기\force_converter.py"
```

Windows 환경에서 `python` 명령을 사용할 수 없는 경우에는 Python 실행 파일에 맞는 명령으로 실행합니다.

프로그램은 별도의 명령줄 인자를 받지 않으며, 실행하면 `공학용 단위 변환기` 창이 열립니다.

### 단위 변환

`단위 변환` 탭에서 분야, 값, 입력 단위, 변환 단위를 선택합니다. 값을 입력하면 결과가 자동으로 계산되며, `변환` 버튼 또는 Enter 키로 변환 기록을 남길 수 있습니다.

지원 분야와 단위는 다음과 같습니다.

| 분야 | 지원 단위 |
| --- | --- |
| 힘 | `N`, `kN`, `MN`, `kgf`, `lbf` |
| 길이 | `mm`, `cm`, `m`, `km`, `in`, `ft` |
| 질량 | `mg`, `g`, `kg`, `t`, `lb` |
| 압력 | `Pa`, `kPa`, `MPa`, `bar`, `psi` |
| 면적 | `mm²`, `cm²`, `m²`, `km²`, `in²`, `ft²` |
| 부피 | `mL`, `L`, `m³`, `in³`, `ft³` |
| 속도 | `m/s`, `km/h`, `mph`, `knot` |
| 시간 | `s`, `min`, `h`, `day` |
| 에너지 | `J`, `kJ`, `Wh`, `kWh`, `kcal` |
| 일률 | `W`, `kW`, `MW`, `hp` |
| 토크 | `N·m`, `kN·m`, `kgf·m`, `lbf·ft` |
| 온도 | `°C`, `°F`, `K` |

표시할 소수점 자릿수는 0에서 12 사이로 설정할 수 있으며, 일반 표기와 과학적 표기를 선택할 수 있습니다. 단위 바꾸기, 초기화, 결과 복사, 변환 기록 복원 및 삭제, 밝은 테마와 어두운 테마를 지원합니다.

변환 기록과 계산 기록은 각각 CSV 파일로 저장할 수 있습니다. 마지막으로 사용한 분야, 단위, 소수점, 표기 방식, 각도 모드, 테마는 프로그램 종료 시 `calculator_settings.json`에 저장되어 다음 실행 때 복원됩니다.

### 정상 입력 예시

| 분야 | 값 | 입력 단위 | 변환 단위 | 결과 예시 |
| --- | ---: | --- | --- | --- |
| 힘 | `2` | `kN` | `N` | `2000.000000 N` |
| 길이 | `100` | `cm` | `m` | `1.000000 m` |
| 온도 | `32` | `°F` | `°C` | `0.000000 °C` |

### 공학용 계산

`공학용 계산` 탭에서는 입력한 수식을 자동으로 계산합니다. `DEG` 또는 `RAD` 버튼으로 삼각함수의 각도 모드를 선택할 수 있습니다.

지원하는 연산자와 상수는 다음과 같습니다.

- 연산자: `+`, `-`, `*`, `/`, `//`, `%`, `**`
- 괄호와 단항 `+`, `-`
- 상수: `pi`, `e`
- 함수: `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sqrt`, `log`, `ln`, `abs`, `factorial`
- `^`는 `**`로 바꾸어 처리합니다.

계산 결과 복사, 메모리 지우기(`MC`), 메모리 불러오기(`MR`), 메모리 더하기(`M+`), 메모리 빼기(`M-`), 계산 기록 복원 및 삭제도 제공합니다.

### 정상 입력 예시

계산기 입력창에 다음 수식을 입력할 수 있습니다.

| 입력 | 의미 | 결과 |
| --- | --- | ---: |
| `2 + 3 * 4` | 사칙연산 | `14` |
| `sqrt(16)` | 제곱근 | `4` |
| `sin(30)` (`DEG` 모드) | 사인 | `0.5` |
| `2^3` | 거듭제곱 | `8` |

### 오류 입력 예시

잘못된 입력은 결과 대신 화면에 오류 메시지를 표시합니다.

### 단위 변환 입력

- 값에 `abc` 입력: 숫자로 변환할 수 없어 오류가 표시됩니다.
- 값에 `NaN` 또는 `inf` 입력: NaN과 무한대는 사용할 수 없다는 오류가 표시됩니다.
- 소수점 자릿수를 `13`으로 설정: 0에서 12 사이여야 한다는 오류가 표시됩니다.

### 수식 입력

- `unknown(2)`: 지원하지 않는 수식 오류가 표시됩니다.
- `sqrt()`: 함수는 인자 하나만 사용할 수 있다는 오류가 표시됩니다.
- `factorial(-1)`: 0 이상의 정수만 사용할 수 있다는 오류가 표시됩니다.
- `1 / 0`: 0으로 나눌 수 없어 오류가 표시됩니다.

## CSV 하중 분석기

`load_analyzer.py`는 CSV 파일의 시간별 하중을 분석하고 응력과 그래프를 생성합니다. 기본 입력 파일은 같은 폴더의 `load_data.csv`이며, 명령줄 인자로 다른 CSV 파일을 지정할 수도 있습니다.

### 입력 열과 단위

입력 CSV에는 다음 열이 필요합니다.

| 열 | 설명 | 단위 |
| --- | --- | --- |
| `time_s` | 시간 | s |
| `force_N` | 하중 | N |

응력은 다음 식으로 계산합니다.

```text
stress_MPa = force_N / AREA_MM2
```

### 필요한 라이브러리

- Python
- `pandas`
- `matplotlib`

설치 명령:

```powershell
.\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
```

### 실행 명령

기본 입력인 `load_data.csv`로 실행:

```powershell
.\.venv\Scripts\python.exe ".\하중 분석기\load_analyzer.py"
```

다른 CSV 파일로 실행:

```powershell
.\.venv\Scripts\python.exe ".\하중 분석기\load_analyzer.py" ".\하중 분석기\load_bad.csv"
```

### GUI 실행

CSV 파일을 선택하고 유효 데이터 수와 시간–하중 그래프를 확인하려면 다음 명령을 실행합니다.

```powershell
.\.venv\Scripts\python.exe ".\하중 분석기\load_analyzer_gui.py"
```

Windows에서는 `하중 분석기\run_load_analyzer_gui.bat` 파일을 더블클릭해도 실행할 수 있습니다. 이 실행 파일은 프로젝트의 `.venv` Python 환경을 자동으로 사용합니다.

VS Code에서 `하중 분석기\load_analyzer_gui.py`를 열고 우측 상단의 `Run Python File` 버튼으로 실행할 수도 있습니다. 두 workspace 설정은 쉼표가 포함된 폴더 경로의 PowerShell 해석 문제를 피하기 위해 상위 환경인 `C:\Users\seung\Desktop\코딩\.venv\Scripts\python.exe`를 사용합니다. 설정이 바로 반영되지 않으면 VS Code를 다시 로드하거나 `Python: Select Interpreter`에서 해당 `.venv`를 선택하세요.

GUI 상단의 `CSV 찾아보기` 버튼으로 CSV 파일을 선택하면 읽기 전용 경로 표시 칸과 유효 데이터 수가 갱신됩니다. 단면 종류에 따라 필요한 치수 입력칸만 표시되며, 모든 치수는 mm, 단면적은 mm²로 계산합니다. 지원 단면과 계산식은 다음과 같습니다.

| 단면 | 입력 치수 | 단면적 |
| --- | --- | --- |
| 사각형 | 폭 `b`, 높이 `h` | `A = b × h` |
| 원형봉 | 지름 `d` | `A = π × d² / 4` |
| 원형관 | 외경 `D`, 두께 `t` | `A = π × [D² − (D − 2t)²] / 4` |
| 사각형관 | 외측폭 `B`, 외측높이 `H`, 두께 `t` | `A = B × H − (B − 2t) × (H − 2t)` |
| H형강 | 전체높이 `H`, 플랜지폭 `B`, 웨브두께 `tw`, 플랜지두께 `tf` | `A = 2 × B × tf + (H − 2tf) × tw` |

원형관은 `D > 0`, `t > 0`, `2t < D`, 사각형관은 모든 치수가 양수이고 `2t < B`, `2t < H`, H형강은 모든 치수가 양수이고 `2tf < H`, `tw < B`인 경우에만 분석합니다. 분석 후 최대 응력과 해당 시간을 표시하고, 하단에는 `Time (s)`와 `Stress (MPa)` 축을 사용하는 시간–응력 그래프를 표시합니다.

### 이상화 단면 가정

GUI의 단면적은 하중이 단면 전체에 균일하게 전달되는 이상화된 축방향 하중 모델로 계산합니다. 따라서 응력은 `σ = F / A`인 평균 정상응력이며, 다음 효과는 고려하지 않습니다.

- 굽힘, 전단, 비틀림 및 좌굴
- 응력집중, 모서리 형상, 용접부 및 국부 좌굴
- 재료의 탄성·소성 거동과 안전율
- 단면 치수의 공차와 하중 방향에 따른 비대칭 효과

단면적은 입력한 외형과 두께로부터 계산하며, 원형관과 사각형관은 균일한 벽 두께, H형강은 일정한 플랜지·웨브 두께를 가정합니다. 치수는 모두 `mm`, 단면적은 `mm²`, 하중은 `N`, 응력은 `MPa`입니다. `1 N/mm² = 1 MPa` 관계를 사용합니다.

### 단면적 설정

현재 단면적은 `load_analyzer.py`의 다음 상수로 설정합니다.

```python
AREA_MM2 = 100
```

단면적의 단위는 `mm²`이며, 현재 기준응력은 `6 MPa`입니다. 프로그램은 데이터 개수, 최대 하중과 시간, 최대 응력과 시간, 기준응력 초과 데이터 개수를 출력합니다.

### 출력 파일

실행하면 다음 파일을 생성하거나 갱신합니다.

- `load_result.csv`: 유효한 `time_s`, `force_N`, 계산된 `stress_MPa`
- `load_result.png`: 하중 및 응력 그래프
- `stress_plot.png`: 시간–응력 그래프

시간–응력 그래프는 x축 `Time (s)`, y축 `Stress (MPa)`를 사용하고, 각 데이터를 점과 선으로 표시합니다. 최대 응력 점은 강조 표시하고 시간과 응력 값을 함께 표시합니다.

### 오류 처리 규칙

- `time_s` 또는 `force_N` 열이 없으면 오류를 표시하고 실행을 중단합니다.
- 두 열의 값이 비어 있거나 숫자가 아니면 원본 CSV의 행 번호와 문제값을 알립니다.
- 문제가 있는 행은 계산과 그래프에서 제외합니다.
- 제외한 행 수와 유효한 데이터 수를 출력합니다.
- 유효한 데이터가 하나도 없으면 계산과 그래프 생성을 중단합니다.
- GUI에서 새 CSV를 선택하면 이전 단면적, 최대 응력, 그래프를 지우고 새 데이터로 다시 분석해야 합니다.
- GUI에서 단면 종류나 치수를 변경하면 기존 결과를 무효화하고 `조건변경됨: 다시 분석 필요`를 표시합니다.
- 숫자가 아닌 치수, 빈 치수, 0 이하의 치수, 무한대 치수는 오류로 처리합니다.
- 원형관, 사각형관, H형강의 유효 치수 조건을 만족하지 않으면 오류를 표시하고 분석하지 않습니다.
- 오류가 발생한 CSV나 치수 입력은 이전 분석 결과로 대체되지 않습니다.
- 원본 입력 CSV는 수정하지 않습니다.

## 파일 구성

```text
requirements.txt    # Python 외부 패키지 목록
README.md           # 사용 설명서

단위변환기/
├─ force_converter.py       # 단위 변환기 및 공학용 계산기
└─ run_force_converter.bat  # 단위 변환기 실행 파일

하중 분석기/
├─ load_analyzer.py         # CSV 하중 분석기
├─ load_analyzer_gui.py     # CSV 하중 분석기 GUI
├─ load_data.csv            # 기본 입력 CSV
└─ run_load_analyzer_gui.bat # GUI 실행 파일
```
